## How each number was measured

* **Adaptive Quiz learning state:** 140 labelled rows (4 states), repeated stratified 5-fold CV (5 repeats) on the deployed Random Forest and four baselines.
* **Emotion:** yolov8s.pt fine-tuned for 60 epochs on a 3-class (negative, neutral, positive) face dataset; metrics are the checkpoint's validation scores. Latency is CPU inference on a 640×480 frame at imgsz 640.
* **Retrieval:** known-item search. 100 random textbook chunks (of 1062); the query is one sentence from the chunk ("sentence") or its first 5 content words ("keywords", like a short student query). A hit is any chunk from the same textbook page.
* **Knowledge Maps verification:** 20 true and 20 false Grade 10–11 science claims (each false claim is a one-fact edit of a true one), fast mode, verdicts by `qwen2.5:3b`. Error detection = flagging false claims as incorrect/incomplete; 0 false claims were accepted as correct.
* **Voice Tutor:** 5 syllabus questions through `/api/voice-tutor/ask` (retrieval + `qwen2.5:0.5b`); speech uses OpenAI whisper-1 and tts-1 (cloud, not timed).
* **Narrative Learning:** from `reports/classification/persona_classifier_metrics.md` and `reports/narrative/story_model_comparison/summary.md`.
